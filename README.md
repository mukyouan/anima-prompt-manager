# Anima プロンプト管理ツール

画像生成AIモデル「Anima」向けのプロンプトを、項目ごとに整理・作成・保存できるWebツールです。

カンマ区切りのタグ形式と自然言語の両方に対応しています。入力した内容は自動的に統合され、コピーして画像生成ツールで使用できます。

**β版 / 無料・ブラウザ上で動作**

## 主な機能

- **項目別プロンプト編集**：画風・品質、人物、顔、髪、衣装、構図、背景、光などを個別に管理
- **複数人物対応**：最大6人まで設定可能。複数人物ではA・B・Cなどの識別記号を自動付与
- **モブ・群衆の指定**：主要人物とは別に、背景人物の人数・特徴・配置を設定可能
- **カメラプリセット**：正面、俯瞰、アオリ、広角、アップなどを日本語・英語併記のメニューから選択
- **ネガティブプロンプト**：品質管理など5項目に分けて編集可能
- **自動保存・保存スロット**：最大50件。画像サムネイルやお気に入り機能に対応
- **エクスポート・インポート**：コメント付きTXTおよびJSONバックアップに対応

## 使い方

### 1. プロンプトを入力する

画面右側の各項目に、英語タグや自然言語で入力してください。

例：

```text
adult male, slender, black hair, gray eyes,
fantasy clothing, detailed embroidery,
```

空欄の項目は出力時に省略されます。

### 2. 人物の人数を設定する

基本設定で主要人物の人数を指定します。

- **1人**：通常のプロンプト形式で出力
- **2人以上**：人物ごとにA・B・Cなどの識別記号を自動付与
- **モブ・観衆を追加**：主要人物とは別に、背景人物や群衆を設定

複数人物では「人物同士の関係・位置」欄に英文で位置関係を記述すると、意図を伝えやすくなります。

※ AIモデルの特性上、人物の特徴や配置が正確に反映されることを保証するものではありません。

### 3. カメラを指定する

カメラプリセットのプルダウンから、日本語・英語併記の項目を選択できます。

選択すると、対応する英語タグが入力欄に自動追記されます。繰り返し選択したり、手入力で編集したりすることもできます。

### 4. プロンプトをコピーする

入力内容は画面下部の「統合結果」に自動反映されます。

「統合をコピー」「ポジだけコピー」「ネガだけコピー」から必要な形式をコピーし、画像生成ツールで使用してください。

### 5. 設定を保存する

保存スロットに名前を付けて、プロンプトを保存できます。

- 保存上限は50件
- サムネイル画像を登録可能
- お気に入りは最大5件
- 通常画面にはお気に入り5件＋その他の最新5件を表示
- 「全件一覧」からすべての保存スロットを管理可能

保存したデータは同じブラウザから再度読み込めます。

## バックアップについて

入力内容はブラウザ内に自動保存されますが、ブラウザのデータ削除や別端末への移行によって失われる場合があります。

大切なデータは「JSONでバックアップ」から定期的に保存してください。

JSONバックアップには、保存スロット・サムネイル・編集中の入力内容が含まれます。
