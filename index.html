Animaプロンプト管理ツール

項目別入力・カメラプリセット・A/B/C人物識別・画像付き保存スロット対応の単一HTML版。

基本設定

自動保存対応
主要人物の人数（最大6人）を設定します。2人以上の場合、出力ではA・B…の識別記号を付けます。
主要人物1人＋モブはA/B、主要人物2人＋群衆はA/B/Cで出力します。
自動保存の状態: 未保存
※ 入力内容はブラウザに自動保存されます。同じブラウザで再度開くと、前回の内容を復元します。

保存スロット

localStorage
画像未選択
画像は端末内で長辺320px以下に縮小され、スロット保存時に登録されます。外部サーバーには送信されません。
保存: 0 / 50 お気に入り: 0 / 5 表示: 0 / 10
自動保存は編集中の内容を保持します。保存スロットには名前を付けて複数の設定を保存できます。お気に入り最大5件とその他の最新5件を表示します（保存上限50件）。
保存スロットのバックアップ
保存スロット・サムネイル・編集中の入力をまとめて移行できます。GitHub Pages版への移行時は、このJSONをご利用ください。

エクスポート / インポート

コメント見出し対応
# ===== Face ===== のようなコメントを含め、ポジティブ・ネガティブを1つのファイルに書き出します。
同じ分類の見出しが複数ある場合は内容を結合します。例えば Outfit / Upper body と Outfit / Waist は、どちらも「衣装」に読み込まれます。既存の入力内容は上書きされるため、必要に応じて保存スロットに保存してください。
